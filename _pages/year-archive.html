QDTraj – Diverse Trajectory Primitives for Articulated Object Manipulation

QDTraj is a project for learning diverse and robust trajectory primitives for articulated object manipulation in robotics. It combines trajectory exploration, simulation, and real-world deployment.

Sim-to-Real Chunk-Based Control

Open-source implementation of the Sim-to-Real pipeline for training and deployment of chunk-based VLA manipulation policies.

QDGset – Large-Scale Grasping Dataset

A large synthetic grasping dataset generated with quality-diversity methods, designed to support robotic grasping and manipulation learning.

Dataset

QDG-6DoF – 6-DoF Grasp Sampling with Quality-Diversity

A quality-diversity framework for efficient 6-DoF grasp sampling, with code and related material for robotic grasp generation.

Source code | Project webpage
